# dsh-away-notify · 自主资讯推送

> **声明**：本插件完全由 DeepSeek-V4.1-Flash (1017) 编写，预计会在后续版本添加更多功能。

DSH 插件：主要作用是主动搜索资讯，推送到 DSH 会话。

设置入口：「设置」→「自主资讯推送」。

## 现有功能

- **持续 / 闲置推送切换**：支持持续定时轮询与闲置（离席）单次推送两种运行模式。
- **按喜好采集资讯**：支持配置自定义兴趣词与查询词模板，精准捕捉感兴趣的主题。
- **机器人 IM 同步**：支持通过 `@xmanrui/dsh-im` 同步投递到手机端机器人（支持 QQ、微信、飞书、钉钉、Telegram 等私聊与群聊）。
- **Token 消耗与账单统计**：实时统计每次执行的五桶 Token 用量、耗时及采集降级轨迹，提供日/周/全量透明账单。
- **多源采集与自动回退**：支持内置免 Token 抓取、web_search 搜索、dsh-ego-browser 插件直连及脚本模式，失败自动按序回退降级。
- **极简自定义源**：只需填入网址自动识别网页格式（JSON / RSS / Atom / HTML），支持“追加到搜索”或“只用自定义源”，条目不够时自动顺链接补充同站文章。
- **人设语气自适应**：可根据当前会话自动继承人设语气输出，也可随时切换为纯信息输出。
- **原生助手消息注入**：直接向会话追加事件流，界面显示为正常的 AI 消息，不唤醒大模型、不重复消耗 Token。

## 特色与优势

1. **零外部常驻**：全程在 DSH 主进程内运行，无外部脚本、无开机自启、无注册表修改、无额外 Windows 服务。
2. **零 Token 默认路径**：默认「内置免 Token 抓取 + 模板渲染 + 会话直投」，不耗费大模型 Token，不额外创建会话。
3. **单常驻低开销探测**：闲置探测复用底层 P/Invoke `GetLastInputInfo` 常驻通道，零高频磁盘写入。
4. **两步选会话**：先选工作区、再选里面的会话（读 `$DSH_HOME/storages/workspace.json`，不靠手抄 sessionId）。
5. **多时段**：时段配置可以加任意多段（含跨午夜 `22:00-02:00`），填错当场标红、不保存。
6. **安全进程治理**：直连 ego 浏览器后台运行（自动置于屏幕外 `--window-position=5000,5000` 不抢焦点），执行完毕自动优雅关闭，带卸载兜底清理。
7. **多模式与全景账单**：支持持续运行与闲时单次两种模式，完整记录每次执行的五桶 Token、耗时与降级轨迹。
8. **可选同步到手机**：QQ/微信这类通道是「你先发、桥接才回」，插件塞进会话的消息不会被桥接回传。所以「投递 → 同步到手机」可以选两种方式：**跟着会话走**（群里来的会话发到群、私聊会话发到私聊，按 dsh-im 自己的会话绑定自动对应）或**固定发到一个对话**（全部发到同一个群/私聊）。对话清单直接读 dsh-im 现存的聊天记录，不用手工填 id。
9. **推送显示成助手消息**：推送直接写进会话事件流（`turn/start → step/start → assistant/message → step/end → turn/end`），界面上就是一条 AI 消息，**不唤醒模型、不烧 Token、不会变成「你自己发的」**；会话正在跑别的轮次时这条跳过，下次再推。

## 采集方法

| 方法 | Token | 说明 |
| --- | --- | --- |
| 内置免 Token 抓取 | 0 | 直接抓微博、头条等公开热榜与自定义源（默认） |
| web_search | 有 | 走宿主搜索服务，结果最贴近查询意图 |
| dsh-ego-browser 插件直连 | 0 | 插件直接调用 ego CLI 跑固定脚本，短暂启动一次浏览器 |
| dsh-ego-browser 插件脚本模式 | 有 | 子会话用 ego 工具多步检索，适合复杂版式/需登录页面 |
| 自定义源 | 0 | 你自己填网址的源，自动识别网页格式；可选追加到搜索结果，或只用它 |

「dsh-ego-browser 插件脚本模式」用插件自带的 ego-search skill 文档（`assets/ego-search.SKILL.md`）内联给子会话，不写入 `%DSH_HOME%\skills`，也不需要任何注入操作。

## 推送风格

- **人设语气**：自动（有会话人设就按人设写，没有就直出内容）／总是（交给当前会话人设自由发挥）／关闭（只发内容）。
- **投递详略**：低（只有标题）／中（标题 + 一句摘要）／高（标题 + 两三句要点），只决定每条写多细。
- **每次推送条数**：1~20 条（默认 3），四种采集方法共用；详略档位不参与条数。
- **兴趣范围**：勾选项会拼进查询词，也参与结果排序。
- **查询词模板**：`{interest}` 换成兴趣项、`{date}` 换成当天日期，支持 `|` 分多路。

## 自定义源

只需一行网址，格式自动识别（JSON / RSS / Atom / 网页）。条目不够时插件会顺着同站链接再补几篇同站文章（纯抓取，不花 Token）；抓不到就跳过这个源，不影响其它源。用法二选一：

- **追加到搜索**（默认）：采集方法出结果后，再把自定义源里的新条目补进去。
- **只用自定义源**：只跑这些网址，不跑采集方法，失败也不回退。

## 安装步骤

1. 将包目录放置到 `C:\Users\36004\.dsh\away-notify\`。
2. 在 `C:\Users\36004\.dsh\profiles\desktop\package.json` 的 `dependencies` 中添加：
   ```json
   "dsh-away-notify": "link:C:/Users/36004/.dsh/away-notify"
   ```
3. 在同一文件的 `dsh.profile.bundles` 数组中追加 `"dsh-away-notify"`。
4. 重启 DSH 桌面端客户端。
5. 在「设置」→「自主资讯推送」里选工作区与会话，点「马上试一次」验证。
