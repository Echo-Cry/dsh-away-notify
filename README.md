# dsh-intel-pulse · 资讯脉搏与状态提醒

> **声明**：本插件完全由 DeepSeek-V4.1-Flash (1017) 编写。

DSH 原生全能插件：集「自主资讯全网检索与多端推送」与「会话状态全局系统原生弹窗」于一体。全程宿主主进程轻量运行，零外部常驻服务，兼顾 0 Token 经济性与深度信息获取。

设置入口：「设置」→「自主资讯推送」。

---

## 核心功能

### 一、采集资讯并主动推送
根据设定的偏好自主捕捉全网热点与专业资讯，以原生助手消息形式直接注入目标会话，或同步转发至移动端聊天软件。

- **按喜好采集资讯，支持自定义源**：
  - 支持配置自定义兴趣词与查询词模板（`{interest}` / `{date}`），精准定向跟踪特定领域动态；
  - 极简自定义源：直填任意网址，自动识别 JSON、RSS、Atom 及网页 HTML；条目不足时自动顺着同站链接补充文章（纯抓取、0 Token）；支持「追加到搜索」或「只用自定义源」。
- **多种资讯采集方法与自动回退链**：
  多源采集失败时自动按序平滑降级，确保每次推送稳定产出：
  | 采集方法 | Token 消耗 | 适用场景与说明 |
  | :--- | :---: | :--- |
  | **内置免 Token 抓取** | **0** | 直接抓取微博、头条等公开热榜与自定义源（默认首选） |
  | **web_search** | **有** | 走宿主搜索服务，深度检索最贴近查询意图的内容 |
  | **dsh-ego-browser 插件直连** | **0** | 直接调用 ego CLI 执行固定采集脚本，短暂启动后台浏览器 |
  | **dsh-ego-browser 插件脚本模式** | **有** | 子会话调用 ego 协同工具多步检索，自带内联 skill，适合复杂版式与需登录网页 |
  | **自定义源** | **0** | 用户填写的专属数据源，可独立运行或与搜索结果聚合 |
- **持续推送与闲置推送自由切换**：
  - **持续推送**：按设定时间间隔定时轮询，支持配置多时段（支持跨午夜如 `22:00-02:00`），时段外自动静默；
  - **闲置推送**：复用底层低开销 P/Invoke 常驻通道检测用户离席（离开电脑），闲置达到阈值后触发单次静默汇总推送。
- **独立「资讯收件箱」侧栏面板与纯收录模式**：
  - **资讯收件箱**：DSH 客户端主左侧栏专属入口，瀑布流卡片按时间陈列所有抓取的资讯流，条目清晰展示主标题、详细摘要与来源标识，支持**点击 🔗 原文直接溯源浏览**，并支持历史记录往回翻页与一键刷新；
  - **纯收录模式（`inboxOnly`）**：支持开启「仅收录到收件箱」，无需强制选择投递会话，静默将资讯沉淀到收件箱面板中，不向任何会话发消息、不发手机，免受打扰。
- **支持 IM 插件，消息同步给机器人**：
  无缝对接 `@xmanrui/dsh-im` 扩展生态，支持将资讯自动同步推送到手机端 Telegram、微信、飞书、钉钉等机器人对话。
- **支持 NapCat 插件，消息同步给 NapCatQQ**：
  原生适配 `dsh-onebot-qq`，自动识别 QQ 私聊与群聊会话；支持「跟随会话走」自动对应聊天，或「固定发到一个对话」，实现双端无缝投递。
- **支持人设配置与插件，语气自适应**：
  - **人设语气**：可设为「自动」（继承当前会话人设口吻）、「总是」（由会话角色自由发挥）或「关闭」（纯文本客观呈现）；
  - **投递详略**：低（仅标题）／中（标题 + 一句摘要）／高（标题 + 核心要点）；
  - **条数自由控制**：支持设置每次推送条数（1~20 条），多源聚合按需截取。

### 二、会话状态系统弹窗
全局深度接入 DSH 会话事件流，后台切换、多任务办公或离开屏幕时，不再错过任何会话进展。

- **全场景关键节点提醒**：
  - **AI 回复完成**：长思考或复杂代码生成完毕时即刻通知；
  - **需要用户操作**：触发工具审批确认、交互提问卡片时主动提醒，避免任务被动挂起；
  - **执行出错**：会话抛出异常时及时反馈。
- **官方应用归属与规范图标**：
  对齐 DeepSeek Harness 官方应用标识（AUMID `com.deepseek.dsh`），桌面弹窗正规展示 DSH 官方图标与名称，拒绝 PowerShell 或控制台伪装。
- **跨平台原生轻量适配**：
  零新增第三方 npm 依赖，Windows 走原生 WinRT Toast / 气泡通知，macOS 走 `osascript`，Linux 走 `notify-send`。
- **会话标题智能识别**：
  深度读取宿主持久化会话索引，通知标题直观展示具体会话名称，告别生硬的内部 UUID。
- **OneBot 11 原生直连出站与 NapCat 一键适配**：
  支持直接通过标准 OneBot 11 HTTP 接口将资讯秒级直推到 QQ（私聊/群聊），彻底免受 DSH 会话休眠（retired）或离线阻断；内置 NapCat 本地环境智能检测与 **一键开启 HTTP 3000 服务** 能力，小白用户点选即可完成全部依赖配置。

## 特色与设计优势

1. **零外部常驻，轻量安全**：全程在 DSH 主进程内作为插件运行，无外部定时脚本、无额外常驻 Windows 服务。
2. **原生助手消息注入（0 Token 消耗）**：推送直接写入会话事件流（`turn/start → assistant/message → turn/end`），在界面上表现为正规的 AI 消息，**不唤醒大模型、不重复消耗 Token、不会误显示为「用户自己发的」**。
3. **安全进程治理**：直连 ego 浏览器后台运行（自动置于屏幕外 `--window-position=5000,5000` 不抢占焦点），执行完毕自动优雅关闭，带卸载兜底清理。
4. **全景账单与透明开销**：实时记录每次执行的五桶 Token 用量、耗时及采集降级轨迹，提供日/周/全量透明账单。
5. **两步选会话**：直接读取工作区清单与会话索引，点选即可绑定，无需手工复制会话 ID。

## 安装步骤

### 方式一：插件市场安装（推荐）
在 DSH 桌面端进入「设置」→「插件市场」，搜索 `dsh-intel-pulse` 点击安装即可。

### 方式二：手动 / 本地源码安装
1. 将本插件代码克隆至本地目录，例如：
   ```bash
   git clone https://github.com/Echo-Cry/dsh-intel-pulse.git ~/.dsh/intel-pulse
   ```
   *(Windows 用户对应路径通常为 `%USERPROFILE%\.dsh\intel-pulse`)*

2. 在配置文件 `~/.dsh/profiles/desktop/package.json` 的 `dependencies` 中添加本地引用：
   ```json
   "dependencies": {
     "dsh-intel-pulse": "link:../../intel-pulse"
   }
   ```
   *(或使用绝对路径 `"link:C:/Users/<你的用户名>/.dsh/intel-pulse"`)*

3. 在同文件的 `dsh.profile.bundles` 数组中追加插件名称：
   ```json
   "dsh": {
     "profile": {
       "bundles": [
         "dsh-intel-pulse"
       ]
     }
   }
   ```

4. 重启 DeepSeek Harness 桌面端客户端。
5. 在「设置」→「自主资讯推送」中配置所需的工作区、会话及推送偏好，点击「马上试一次」即可验证。
